# Source Candidates

This file lists candidate sources to investigate. Do not import content until license, version, and allowed use are verified by the project owner.

## Arabic Quran text candidates

### Tanzil

- URL: https://tanzil.net/
- License page: https://tanzil.net/docs/Text_License
- Notes: Commonly used for verified Quran text in apps and websites. Verify current license terms and attribution requirements before use.

### King Fahd Quran Complex

- URL: https://qurancomplex.gov.sa/
- Notes: Official Quran publication/digital resources. Verify access, license, and exact files before use.

### Quran.com / Quran.Foundation developer resources

- URL: https://quran.com/developers
- Notes: Useful for APIs/resources around Quran text, translations, tafsir, audio, and related data. Verify current API terms and content licenses before use.

## Translation candidates

### QuranEnc

- URL: https://quranenc.com/
- Notes: Provides translations of meanings in many languages. Verify API/license/attribution terms and exact translation source before use.

### Quran.com translation resources

- URL: https://quran.com/developers
- Notes: Verify specific translation licenses and attribution requirements.

## Tafsir candidates

### Quran.com tafsir resources

- URL: https://quran.com/developers
- Notes: Verify exact tafsir text source, language, edition, and license before importing.

## Approval checklist

Before a source is approved:

- Confirm provider and publisher.
- Confirm license allows the intended website/app use.
- Confirm whether attribution is required.
- Confirm whether modifications are forbidden.
- Confirm version/date.
- Save source file checksum.
- Save import manifest.
- Run verification.
